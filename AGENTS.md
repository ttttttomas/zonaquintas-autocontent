# Creative production rules — ZonaQuintas + iWeb

Before producing a reel, read `docs/creative-production.md` and the corresponding `brands/<brand>/brand.md`.

## Required HyperFrames skills
Install the official core skill set in the working agent environment using `npx hyperframes skills update`. Read `hyperframes-core`, `hyperframes-creative` (especially `references/house-style.md`, `references/video-composition.md`, `references/story-spine.md`), `hyperframes-animation`, and the relevant workflow skill (`product-launch-video`, `motion-graphics`, or `general-video`). These are agent instructions, not a replacement for a model or creative assets.

## Hard rules
- Never invent a brand logo, property listing, testimonial, performance statistic, client, price, guarantee, or product capability.
- Never expose client records, passenger names, bookings, or other personal data in visuals; anonymize before export.
- Every video needs a real audience, one concrete problem, one useful message, an evidence-backed visual, and one CTA.
- Do not reuse the same generic title/subtitle/CTA layout across all pieces.
- Each shot must serve the narrative; real UI and authorized property footage take priority over decorative abstractions.
- No unattended publishing. Require editorial and visual approval before external distribution.
- Reject briefs that lack source evidence or approved visual assets. Use a clearly labeled internal draft instead.
- Never commit API keys, private client material, or copyrighted unlicensed footage.
